# Anatomy kit (vendored)

The isometric drawing kit from [wheresryan22/anatomy](https://github.com/wheresryan22/anatomy),
MIT licence (see `LICENSE`), copied unchanged at commit
`1482e8469b0a9e0d8cc18ea2740a01423d29ae80`:

- `iso-kit.ts` (camera, solids, parts helpers), `iso.css` (tokens and styles)
- `react/draw.tsx` (server-safe components), `react/live.tsx` (client hooks)

Keep these files unchanged so they can be updated from upstream. Cradle's
palette is applied by overriding the `--anatomy-*` tokens in the figure's own CSS.
